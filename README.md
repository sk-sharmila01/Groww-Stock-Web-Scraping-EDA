# Groww-Stock-Web-Scraping-EDA
A Python-based web scraping and Exploratory Data Analysis (EDA) project on Groww stocks. Uses Requests and BeautifulSoup to extract stock names, URLs, and available stock market information, and Pandas, NumPy, Matplotlib, and Seaborn for data cleaning, statistical analysis, and visualization.

Groww-Stock-Web-Scraping-EDA
Python-based web scraping and Exploratory Data Analysis (EDA) project
focused on stock information available on Groww.

📊 Groww Stock Market Web Scraping and EDA
A Python-based data analytics project designed to collect available
stock information from Groww and explore the data through cleaning,
statistical analysis, and visualizations.

🎯 Project Overview
This project uses web scraping to collect stock names, stock-page URLs,
and available stock-market information from Groww. The collected data is
organized and analyzed to understand data distributions, compare
financial metrics, and explore relationships between selected stock
variables.

🔍 Key Analysis
- Scraping stock names and stock-page URLs from Groww
- Extracting available stock metrics from individual stock pages
- Data cleaning and numeric data conversion
- Missing-value and duplicate checks
- Univariate analysis using histograms and boxplots
- Bivariate analysis using scatter plots
- Multivariate analysis using a correlation matrix and heatmap
- Comparing stocks by selected metrics, including market
  capitalization, percentage change, and ROE

📈 Data Fields & Metrics
Depending on the information available on Groww pages, the notebook may
collect or analyze fields such as:
- Stock name and stock URL
- Current price and daily percentage change
- 52-week high and 52-week low
- Opening price and previous close
- Trading volume and market capitalization
- Return on Equity (ROE)
- P/E ratio, EPS, and P/B ratio
- Dividend yield, industry P/E, book value, debt-to-equity ratio, and
  face value
The exact fields available depend on the page response when the notebook
runs. Some fields may contain missing values.

▶️ How to Run
1. Clone or download this repository.
2. Install the required libraries:
   pip install requests beautifulsoup4 pandas numpy matplotlib seaborn jupyter
3. Start Jupyter Notebook:
   jupyter notebook
4. Open Web Scaraping Project.ipynb.
5. Run the notebook cells from top to bottom to perform scraping and
   analysis.
   
🎯 Learning Outcome
This project helps build practical skills in Python-based web scraping,
data collection, data cleaning, exploratory data analysis, statistical
interpretation, and data visualization. It also demonstrates how scraped
stock-market information can be organized to explore patterns and
relationships between financial metrics.

⚠️ Important Notes
- This is an educational data-analysis project, not investment advice.
- Results reflect the data available when the notebook is executed and
  may change over time.
- Groww's page structure or access policies may change and affect
  scraping.
- Use responsible request rates and respect the website's terms and
  applicable policies.
- Validate scraped values before using them for financial decisions.
